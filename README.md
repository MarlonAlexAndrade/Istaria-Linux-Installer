# Istaria: Chronicles of the Gifted — Linux
**Author / Autor:** Marlon Alex Andrade

---

## 🇧🇷 Português

### Sobre o projeto
Este repositório contém ferramentas para jogar **Istaria: Chronicles of the Gifted** no Linux de forma simples, sem precisar de comandos ou conhecimento técnico.

### O que está incluído

| Ferramenta | Descrição |
|---|---|
| 📦 **Installer** | Instala o Istaria automaticamente no Linux |
| 🎮 **Mods** | Gerencia mods do jogo (MapPack 5.0 e futuros) |

### Estrutura do repositório
```
istaria-linux/
  installer/
    Instalar-Istaria.desktop  ← clique para instalar
    instalar-istaria.sh
    README.md
  mods/
    Istaria-Mods.desktop      ← clique para gerenciar mods
    istaria-mods.sh
    README.md
```

### Como usar
- Para instalar o jogo → veja `installer/README.md`
- Para instalar mods → veja `mods/README.md`

### Distribuições suportadas
- Ubuntu / Debian / Linux Mint / Pop!_OS
- Arch Linux / Manjaro / EndeavourOS
- Fedora / RHEL / CentOS

### Dependências instaladas automaticamente
Wine, Winetricks, Java 21, Java 8 (Wine), vcrun2005, vcrun2008, DirectX 9, DirectPlay, corefonts.

## 🇺🇸 English

### About
This repository contains tools to play **Istaria: Chronicles of the Gifted** on Linux easily, no commands or technical knowledge required.

### What's included

| Tool | Description |
|---|---|
| 📦 **Installer** | Automatically installs Istaria on Linux |
| 🎮 **Mods** | Manages game mods (MapPack 5.0 and future ones) |

### Repository structure
```
istaria-linux/
  installer/
    Instalar-Istaria.desktop  ← click to install
    instalar-istaria.sh
    README.md
  mods/
    Istaria-Mods.desktop      ← click to manage mods
    istaria-mods.sh
    README.md
```

### How to use
- To install the game → see `installer/README.md`
- To install mods → see `mods/README.md`

### Supported distributions
- Ubuntu / Debian / Linux Mint / Pop!_OS
- Arch Linux / Manjaro / EndeavourOS
- Fedora / RHEL / CentOS

### Automatically installed dependencies
Wine, Winetricks, Java 21, Java 8 (Wine), vcrun2005, vcrun2008, DirectX 9, DirectPlay, corefonts.
