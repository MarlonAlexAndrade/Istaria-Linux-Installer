# Istaria: Chronicles of the Gifted — Linux Installer
**Author / Autor:** Marlon Alex Andrade

---

## 🇧🇷 Português

### O que é isso?
Um instalador automático do **Istaria: Chronicles of the Gifted** para Linux.  
Suporta: Ubuntu, Debian, Arch Linux e Fedora.

### O que você vai precisar
- Conexão com a internet
- Os dois arquivos na mesma pasta:
  - `Instalar-Istaria.desktop`
  - `instalar-istaria.sh`

### Passo a passo

**1.** Extraia os dois arquivos e coloque-os na **mesma pasta**.

**2.** Clique duas vezes no arquivo **`Instalar-Istaria.desktop`** (ícone de controle de videogame).

**3.** Uma janela vai perguntar se deseja executar — clique em **"Run"** ou **"Executar"**.

**4.** O terminal vai abrir. Pressione **ENTER** para iniciar a instalação.

**5.** Digite sua **senha sudo** quando solicitado e pressione ENTER.

**6.** O instalador vai baixar e configurar as dependências automaticamente.  
Quando aparecer alguma janela perguntando sobre instalar algo, clique em **"Não"** ou **"No"** em todos.

**7.** Aguarde o download do jogo (pode demorar dependendo da sua conexão).

**8.** Ao final, o instalador vai perguntar se deseja **remover os arquivos de instalação** — clique em **"Sim"**.

**9.** Se aparecer uma janela perguntando se deseja **criar uma conta**, clique em **"Não"** (caso já tenha uma conta).

**10.** Pronto! Pressione a tecla **Windows**, pesquise por **"Istaria"** e clique para jogar. 🐉

## 🇺🇸 English

### What is this?
An automatic installer for **Istaria: Chronicles of the Gifted** on Linux.  
Supports: Ubuntu, Debian, Arch Linux and Fedora.

### What you will need
- An internet connection
- Both files in the same folder:
  - `Instalar-Istaria.desktop`
  - `instalar-istaria.sh`

### Step by step

**1.** Extract both files and place them in the **same folder**.

**2.** Double-click the **`Instalar-Istaria.desktop`** file (gamepad icon).

**3.** A window will ask if you want to run it — click **"Run"**.

**4.** The terminal will open. Press **ENTER** to start the installation.

**5.** Type your **sudo password** when prompted and press ENTER.

**6.** The installer will automatically download and set up all dependencies.  
If any window pops up asking to install something, click **"No"** on all of them.

**7.** Wait for the game to download (may take a while depending on your connection).

**8.** At the end, the installer will ask if you want to **remove the installation files** — click **"Yes"**.

**9.** If a window appears asking if you want to **create an account**, click **"No"** (if you already have one).

**10.** Done! Press the **Windows key**, search for **"Istaria"** and click to play. 🐉
